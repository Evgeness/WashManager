# WashManager

> Приложение для бронирования стиральных и сушильных машин в общежитии.

Состоит из двух частей:
- **Frontend** — React + TypeScript + MUI 
- **Backend** — FastAPI + PostgreSQL + SQLAlchemy 

---

## 🎯 Назначение приложения

**WashManager** — веб-приложение для студентов общежития, которое позволяет:

- просматривать актуальное состояние стиральных и сушильных машин;
- бронировать свободные временные слоты;
- вставать в очередь на занятые слоты;
- получать напоминания о завершении стирки;
- вести историю своих бронирований.

---

## 👤 Пользовательские сценарии

1. **Просмотр главной страницы** — пользователь видит ближайшую бронь и количество свободных слотов на сегодня.
2. **Просмотр расписания** — пользователь открывает экран «Расписание», выбирает нужный день и видит статус всех машин по временным слотам (свободно / занято / очередь).
3. **Бронирование слота** — пользователь кликает на свободный слот и подтверждает бронирование.
4. **Просмотр своих броней** — пользователь открывает экран «Мои брони», видит активные брони и историю.
5. **Отмена брони** — пользователь может отменить активную бронь.
6. **Регистрация и вход** — демонстрационные страницы регистрации и входа.

## 🖼 Основные экраны

| Экран | Маршрут | Назначение |
|---|---|---|
| **Dashboard** | `/` | Главная. Две карточки: ближайшая бронь и свободные слоты на сегодня. |

## 🛠 Стек технологий

### Frontend
- **React 18** — библиотека для построения пользовательских интерфейсов
- **TypeScript** — статическая типизация
- **Vite** — сборщик и dev-сервер
- **React Router v6** — клиентская маршрутизация
- **MUI (Material UI) v6** — библиотека UI-компонентов
- **MUI Icons** — набор иконок
- **Google Fonts (Inter)** — шрифт интерфейса

### Backend
- **FastAPI** — современный веб-фреймворк для Python
- **Uvicorn** — ASGI-сервер
- **PostgreSQL** — реляционная база данных
- **SQLAlchemy 2.0** — ORM для работы с БД
- **Pydantic** — валидация данных и настройки
- **Pydantic Settings** — чтение конфигурации из `.env`

### Архитектура Backend

    api/routes/ — HTTP-эндпоинты (роуты);

    models/ — SQLAlchemy-модели (таблицы БД);

    schemas/ — Pydantic-схемы для валидации;
    
    crud/ — бизнес-логика работы с БД;

    db/ — подключение к БД и сессии;

    core/ — конфигурация.

### Единое оформление (Frontend)

Все компоненты используют общую тему `src/app/theme.ts`:

- 🌙 **Тёмная тема** (`mode: 'dark'`)
- 🎨 Единая палитра: синий (`primary`), голубой (`secondary`), зелёный (`success`), жёлтый (`warning`), красный (`error`)
- 📐 Скруглённые углы: `borderRadius: 10` для общих компонентов, `14` для карточек
- 🔤 Шрифт Inter, единые размеры заголовков (`h1`, `h2`, `h3`)
- 📱 Базовая адаптивность: сетки `xs` / `md`, `Container maxWidth={false}`
